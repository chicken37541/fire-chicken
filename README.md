# 界面之外 · AI 资讯简报

黑白风格静态网站，支持资讯搜索、分类、排序、收藏及 JSON 导出。

## 首次发布

打开 https://github.com/chicken37541/fire-chicken/settings/pages ，在 Build and deployment 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

点击 Save，等待 GitHub Pages 构建完成。

网站地址：https://chicken37541.github.io/fire-chicken/

后续更新 main 分支的 index.html 后，GitHub Pages 会重新发布。
